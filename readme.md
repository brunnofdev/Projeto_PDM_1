# Conversor de Temperatura - Projeto PDM 1

Aplicativo Android simples para conversão de temperaturas, desenvolvido em Kotlin como parte do Projeto 1 para a disciplina de Programação para Dispositivos Móveis (PDM).

## Tecnologias Utilizadas

*   Android Studio
*   Kotlin
*   Gradle

## Como executar o projeto

1. Faça o clone deste repositório para a sua máquina local.
2. Abra a pasta do projeto (`Projeto_PDM_1-main`) no Android Studio.
3. Aguarde o Android Studio realizar a sincronização do Gradle (Gradle Sync).
4. Selecione um emulador ou conecte um dispositivo físico com depuração USB ativada.
5. Clique no botão "Run" (ou pressione `Shift + F10`) para compilar e executar o aplicativo.

## Estrutura do Código

*   **Lógica:** O código principal do aplicativo está localizado em `app/src/main/java/com/brunnofdev/conversordetemperatura_projetopdm1/MainActivity.kt`.
*   **Interface:** Os layouts e configurações visuais estão na pasta `app/src/main/res/`.
